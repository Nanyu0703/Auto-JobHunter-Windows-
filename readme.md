# Auto JobHunter（Windows 本地爬虫版）

这是一个面向 Windows 的本地“岗位雷达”。它关注岗位新增、变化、失效和匹配程度，不调用 GPT，不修改简历，也不依赖飞书。

## 已保留功能

- BOSS直聘、前程无忧、猎聘岗位采集
- 平台、关键词、城市、薪资和页码表单
- 招聘平台登录与验证码人工接管
- 抓取日志、任务停止和失败提示
- SQLite 本地去重与保存
- 稳定岗位指纹去重，同一岗位再次出现时更新而不是新增
- 新增、高匹配、有效、跟进中、已失效五类雷达视图
- 本地规则评分、排除词、薪资解析和收藏/投递/沟通状态
- 岗位筛选、详情查看、删除和 CSV 导出

智联招聘暂未启用，因为原项目没有对应的爬虫文件。

### BOSS 低频列表模式

BOSS 默认只读取搜索结果列表，不再自动逐个请求岗位详情。每页的远程请求量从约 16 次降低到约 1 次；岗位名称、公司、城市、薪资、经验、学历、技能标签和来源链接仍会保存。需要完整 JD 时，可从本地岗位库打开原页面人工查看。

系统不会伪造鼠标轨迹、绕过验证码或进行自动投递。出现登录或安全验证时，会暂停并交给用户处理。

## Windows 环境要求

- Windows 10/11 64 位
- Python 3.10–3.13，推荐 Python 3.12 64 位
- Node.js 20 或更高版本
- Microsoft Edge

## 首次安装

在项目根目录打开 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup_windows.ps1
```

安装脚本会创建 `.venv-windows`、安装爬虫依赖、安装 Chromium，并初始化本地数据库。

## 启动

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start_windows.ps1
```

启动后会打开：

- 网页：http://127.0.0.1:3000
- 本地接口：http://127.0.0.1:8000

请保留启动后出现的两个 PowerShell 窗口。关闭它们会停止项目。

## 使用流程

1. 在左侧选择招聘平台。
2. 填写岗位关键词、城市、薪资和页数。
3. BOSS直聘首次使用时，点击“打开 BOSS 登录页”，在 Edge 完成扫码或安全验证。
4. 返回网页点击“开始抓取”。
5. 在运行日志中查看进度；需要中止时点击“停止任务”。
6. 抓取完成后查看新增、高匹配及失效岗位，并维护收藏/投递状态。

## 数据位置

岗位保存在：

```text
data/job_hunter.db
```

主要数据表为 `raw_jobs`。系统使用平台、公司、岗位和城市生成稳定指纹；即使招聘网站的临时链接变化，同一岗位也会更新首次/最后出现时间和出现次数，不会继续无限新增。历史重复记录会标记并隐藏，不会在迁移时直接删除。

## 当前运行结构

```text
start_windows.ps1
  ├─ data/db_manager.py                 初始化 SQLite
  ├─ jobhunter-backend/crawler_main.py  纯爬虫后端
  └─ frontend                           本地管理网页
```

原项目中的 AI、简历和飞书源码暂时保留作历史参考，但启动脚本不再加载这些模块，安装清单也不再安装对应依赖。

## 风控说明

招聘平台可能要求扫码、短信、验证码或安全验证。项目不会绕过这些验证，出现验证页面时请人工完成。建议每次先抓取一页，确认账号状态正常后再增加页数。
